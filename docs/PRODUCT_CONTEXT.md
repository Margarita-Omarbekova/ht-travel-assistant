# Product Context — HT Travel Assistant

## Идея продукта

Travel Assistant сначала помогает пользователю понять, **какой отдых ему подходит**, а уже потом подбирает товар.

Порядок:
1. Выяснить потребности и образ отдыха.
2. Предложить страны / регионы / курорты / места / досуг.
3. Помочь выбрать сценарий поездки.
4. Объяснить, как поездку лучше собрать.
5. Только затем подобрать продукт:
   - пакетный тур;
   - перелёт + отель отдельно;
   - бюджетные и премиальные сценарии.

Главный принцип: **сначала продаём идею путешествия, потом товар**.

## Что должен учитывать ассистент

- состав туристов;
- возраст детей;
- гражданство;
- даты и сезон;
- бюджет;
- город вылета;
- продолжительность;
- допустимое время в дороге;
- прямой рейс / пересадки;
- отношение к визам;
- климат;
- безопасность;
- чистота / санитария;
- количество людей;
- комфорт в отеле;
- питание;
- тип сервиса;
- активность;
- досуг;
- визуальные референсы пользователя.

## Сезонность

Сезонность должна работать не только на уровне страны, но и глубже:

country → region → resort → area/bay → hotel

Примеры:
- Египет: в разные месяцы важна защищённость бухты от ветра.
- Таиланд: летом может быть предпочтительнее Самуи, зимой — Пхукет / Паттайя.

## Комплектация поездки

Ассистент должен рекомендовать не только отель, но и состав продукта:
- когда стоит брать питание в отеле;
- когда выгоднее есть вне отеля;
- трансфер;
- аренда авто;
- багаж;
- страховка;
- экскурсии;
- другие услуги.

Не предлагать услугу только потому, что она доступна. Объяснять, нужна ли она именно в этой поездке.

## Каналы

Telegram — MVP-канал.

Архитектура должна быть channel-agnostic, чтобы позже использовать то же ядро:
- на сайте;
- в мобильном приложении;
- в других мессенджерах.

## MVP-логика

DISCOVERY
→ DESTINATION_SELECTION
→ DESTINATION_EXPLORATION
→ TRIP_CONFIGURATION
→ PRODUCT_SEARCH
→ COMPARISON
→ BOOKING_OR_MANAGER

На старте LLM отвечает за естественный диалог и объяснение.
Правила, актуальные данные и коммерческая логика должны жить в контролируемом backend-слое.
